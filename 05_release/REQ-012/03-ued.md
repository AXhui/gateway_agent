## 3. 交互流程描述

### 3.1 主路径 A：扫描入网（核心路径）

```
设备数采页 → LoRaWAN扫描配置页
  → 配置 AppKey（勾选 Milesight 默认 Key / 导入文件 / 手动输入自定义 Key）
  → 点【开始扫描】（无任何 Key 时按钮置灰不可点）
  → 跳转至扫描确认页，同时开始扫描
  → （可选）行内编辑 / 单设备编辑 / 多设备编辑抽屉 / 忽略
  → 勾选设备（单选/多选/全选）
  → 点【添加设备】→ 确认弹窗 → 确认
  → 提示「xx个设备添加成功」+ 刷新当前页 + 已添加设备从扫描确认页移除
```

### 3.2 主路径 B：放弃扫描

```
扫描确认页 → 点【放弃扫描】→ 确认弹窗 → 确认
  → 结束扫描状态 + 清空扫描确认页中所有未添加的设备（不添加到网关）
```

### 3.3 路径 C：扫描中重新进入配置页

```
扫描中 → 从设备数采页重新进入 LoRaWAN扫描配置页
  → 允许新增/删除 AppKey；已扫描到的设备及其匹配的 AppKey 保留（即使该 AppKey 在配置页被删除）
  → 【开始扫描】按钮变为【应用】按钮
```

### 3.4 路径 D：全局提示条

```
任意页面（扫描中）→ 提示条「正在LoRaWAN扫描中」+（有新设备时）红点 + 设备数
  → 点击提示条 → 跳转扫描确认页（不中断扫描）
  → 红点去除、提示条变灰、设备数保留
```

### 3.5 设备状态变化（展示口径，判定细节见 04-dev.md §3）

- OTAA：Join Request + Join Accept → 超时时间内收到正常上行 → **在线**；MIC 校验失败 → **入网失败**（原因：密钥错误）；Join Accept 后超时未收到有效上行 → **入网失败**（原因：节点未收到入网应答包）
- ABP：收到上行且解析正常 → **在线**；上行 MIC 校验失败 → **入网失败**（原因：密钥错误）
- 失败原因展示：入网失败状态的**右侧**以提示形式展示

### 3.6 忽略流转

```
发现设备 Tab ⇄ 已忽略设备 Tab
  点【忽略】→ 设备从发现 Tab 移到已忽略 Tab（信号与最新更新时间仍正常更新）
  点【取消忽略】→ 设备移回发现 Tab，仍按最后更新时间排序
```

### 3.7 异常路径

- URL 直入扫描确认页且当前不处于扫描中 → 弹窗提示「请先完成扫描配置，页面即将返回配置步骤。」→ 3 秒后自动跳转回扫描配置页
- 从扫描确认页回退/退出 → 未被添加的设备（**包括已忽略设备**）保持不变，扫描不中断

## 6. 状态枚举

### 6.1 设备状态（新增「入网失败」）

| 枚举 | 取值 | 展示形式 |
|---|---|---|
| 设备状态（新增值） | **入网失败** | 设备数采页状态列；状态右侧以提示展示失败原因（非独立颜色状态，原因仅作注记） |
| 设备状态（既有值） | 在线 / 离线 等 | 既有展示不变（完整既有枚举清单 PRD 未列，待确认） |

### 6.2 入网失败原因（仅作状态右侧提示，不作为独立设备状态）

| 枚举 | 取值 | 展示形式 |
|---|---|---|
| 失败原因 1 | **密钥错误**（OTAA：Join Request MIC 校验失败；ABP：上行 MIC 校验失败） | 「入网失败」状态右侧提示 |
| 失败原因 2 | **节点未收到入网应答包**（OTAA：Join Accept 下发后超时未收到有效上行） | 同上 |

> EG71 与 UG6x 差异（5 条，见 04-dev.md §3.3）：无「未收到JoinRequest」原因；不把两类原因做成独立状态；ABP 无「入网超时」；超时时间取配置内值；新状态作为全局对象传 BACnet/Modbus。

### 6.3 激活设置（单选）

| 取值 | 默认选中条件 | 可选性 |
|---|---|---|
| 默认值 | DevEUI 为 Milesight 设备（oui 匹配：DevEUI 以 **24E124** 开头，或设备型号为 Milesight） | 非 Milesight 设备时**不可选中**（禁用） |
| 自定义值 | DevEUI 非 Milesight 设备 | 可选 |

### 6.4 设备型号识别（扫描确认页，按优先级）

| 优先级 | 规则 |
|---|---|
| 1 | 系统通过 DevEUI 识别出设备型号 → 自动填充 |
| 2 | 匹配到多个型号时：**内置设备库型号 > 自定义设备型号 > 自定义设备型号 ID 靠后的设备** |
| 3 | 内置设备库型号重复 → 显示多个（如 AM102/AM102L/AM103/AM103L） |
| 兜底 | 无法识别 → 显示 **None** |

### 6.5 信号强度三档（扫描确认页）

| 档位 | 判定 | 展示 |
|---|---|---|
| 高 | SNR 和 RSSI **都高** | 图示高档 + 显示具体值 |
| 中 | 其他情况 | 图示中档 + 显示具体值 |
| 低 | SNR、RSSI **任意一个低** | 图示低档 + 显示具体值 |

> 图示与逻辑沿用设备数采页 LoRaWAN 信号列；SNR/RSSI 高低判定的**阈值数值 PRD 未给**，待确认（以既有信号列实现为准）。

### 6.6 扫描确认页 Tab 与按钮态

| 枚举 | 取值 | 说明 |
|---|---|---|
| Tab | 发现设备 / 已忽略设备 | 两 Tab 均有设备列表，仅操作不同 |
| 【开始扫描】按钮态 | 置灰（无任何 Key）/ 可点（配置页首次）/ 文案变【应用】（扫描中重新进入） | |

### 6.7 引导横幅文案（扫描确认页顶部，原文照录）

> 「扫描仅能发现OTAA入网模式的设备，请核对 DevEUI是否与您的设备一致。若长时间未发现目标设备，请确认设备处于开机状态，缩短设备与网关距离并重启设备后再试。」

### 6.8 AppKey 导入横幅文案（原文照录）

| 场景 | 文案 |
|---|---|
| 文件超过 1M | 文件超过1M无法上传，请重新上传文件 |
| 数量超限 | AppKey数量超过1000条，当前仅能再添加N条，请重新上传文件（N 为实际剩余可添加数量） |
| 无 AppKey 表头 | 文件内没有找到AppKey，请重新上传文件 |
| 存在非法 AppKey | 存在非法AppKey，请重新上传文件（全部失败，不导入任何一条） |

### 6.9 反馈与弹窗文案（原文照录）

| 场景 | 文案 |
|---|---|
| 扫描确认页空态 | 扫描进行中，离开此页面不会打断扫描 |
| 添加成功 | xx个设备添加成功（并刷新当前页） |
| 添加冲突 | xx个设备已存在 |
| URL 直入非扫描中 | 请先完成扫描配置，页面即将返回配置步骤。（3 秒后跳回扫描配置页） |
| 全局提示条 | 正在LoRaWAN扫描中 |
| 添加设备确认弹窗 / 放弃扫描确认弹窗 | 文案 PRD 未给，**待确认**（以 Figma 为准） |
