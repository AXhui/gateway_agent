# UED Next · MS AI 协作伙伴

浅色极简 HTML 比赛演讲，包含 **P0 介绍视频 + 12 屏主讲 + 4 屏备用答辩页**。

## 打开演讲

下载本目录及其子目录后，用 Chrome 或 Edge 打开 [index.html](index.html)。所有视频、截图、CSS 和 JavaScript 均在本地，无需网络、依赖安装或构建。GitHub 文件查看页显示的是源代码，不会直接运行 HTML。

字体已内置在 `assets/fonts/`：中文、英文、数字和讲稿统一使用 Noto Sans SC，可离线加载，无需对方安装。复制时保留完整字体目录；开源许可见其中 `OFL.txt`。[字体加载检查](预览/字体检查.json)已确认标题、数字和标志均使用内置字体。

P0 视频约 71 秒，保留声音，可手动播放或跳过；正式主讲建议 9 分 30 秒，完整播放开场视频后约 10 分 41 秒。

| 操作 | 方式 |
| --- | --- |
| 下一步 / 下一屏 | 滚轮向下、→、空格、PageDown |
| 上一步 / 上一屏 | 滚轮向上、←、PageUp |
| 目录与备用页 | M |
| 全屏 | F |
| 独立讲稿窗口 | P |
| 重播当前屏 | R |
| 视频播放 / 暂停 | V，或播放器控件 |
| 回到开场视频 / 收尾 | Home / End |

一次滚动手势只推进一步，避免惯性连跳。视频控件、目录和截图查看器保留自己的滚轮操作。详细说明见 [使用说明](使用说明.md)。
