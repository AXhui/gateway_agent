# UED Next · HTML 演讲

双击同目录的 `index.html`，建议使用 Chrome 或 Edge。所有 CSS、脚本、图片和视频都在本地，演讲时无需网络、安装依赖或启动服务。移动或复制时，请保留整个 `HTML演讲` 文件夹。

## 演讲前

打开页面首先显示 **P0 介绍视频**，使用原素材「方案介绍.mov」无损封装为本地 MP4，约 71 秒，保留声音。手动播放，播完停留；按 →、空格或点击「进入正式开场」可跳过。主讲第一页按 ← 可返回视频，Home 也会返回 P0；目录最前面有介绍视频入口。

完整播放视频后，加上原定 9 分 30 秒主讲，总时长约 **10 分 41 秒**。若比赛限制 10 分钟，请跳过视频或适当压缩后续讲解。

1. 把浏览器窗口移动到投影屏幕，按 **F** 或点击底部「全屏」。
2. 点击「讲稿」或按 **P**，将独立讲稿窗口移回笔记本屏幕。若浏览器拦截弹出窗口，允许后重试。
3. 讲稿窗口显示当前画面预览、讲稿、当前步骤提示、下一屏标题和手动计时器。计时建议 09:30，备用页不计入。
4. 试播第 7、9 屏的视频，确认投影与浏览器音量。主流程录屏没有音轨；配合现场讲解即可。

## 操作

| 操作 | 快捷键 |
| --- | --- |
| 下一步 / 下一屏 | 滚轮向下、→、↓、空格、Enter、PageDown |
| 上一步 / 上一屏 | 滚轮向上、←、↑、PageUp、Backspace |
| 目录与备用页 | M |
| 重播当前屏，从第一步重新推进 | R |
| 讲稿窗口 | P |
| 全屏 | F；浏览器 F11 也可使用 |
| 当前主流程视频播放 / 暂停 | V |
| 返回介绍视频 / 收尾 | Home / End |
| 关闭目录或图片查看器 | Esc |

一屏有多步时，先完成分步展示，再进入下一屏。主讲第 12 屏停留，不会自动进入备用页。鼠标移动后会短暂显示底部工具栏，也可以将鼠标移到底部保持显示。

滚轮支持逐步翻页，并有防连跳处理：一次滚动手势只推进一步，停止滚动后再滚动可继续。请将鼠标放在演讲正文或空白处；视频控件、底部工具栏、目录和截图查看器保留自身操作。讲稿窗口的滚轮用于滚动讲稿。

视频默认不自动播放。第 7 屏分为三个阶段，点击左侧阶段或按下一步切换，再点击「播放片段」。第 9 屏以 1.5 倍速播放约 35 秒的转稿片段。片段到达结尾自动暂停；切屏、切步骤、打开目录或截图时，视频会暂停。焦点在原生视频控件上时，空格和方向键交由视频控件使用；可使用底部翻页按钮，或点击视频外的空白处后再翻页。

视频无法播放时自动显示备用截图，也可以手动点击「切换截图」。备用页中的两段拓展视频仅在答辩时按需播放。

截图可以点击打开原图，滚轮或加减按钮缩放，拖动查看。工具栏的「减弱动效」可以关闭动画，同时尊重操作系统的减少动态效果设置。

## 内容与素材

- `content.js`：每屏正文、独立讲稿、步骤提示及片段时间。修改文本无需构建。
- `styles.css`：全套视觉与动效，舞台基准 1920×1080，按屏幕等比缩放。
- `app.js`：翻页、视频、截图、目录、讲稿同步与计时。
- `assets`：从原方案复制的真实截图和录屏；Figma 与拓展视频封面从对应录屏提取。
- `预览`：浏览器实拍的开场、关键页面与总览，供快速检查。

本演讲包未接入任何业务 API，也不会触发飞书通知、生成设计或操作 Figma。演示内容是已有真实项目的录屏与截图。

## 数据口径

主讲约 9 分 30 秒，12 屏建议时间总计 570 秒。时长为演讲节奏参考，不会强制自动翻页。

- 4–10 天到约半天比较的是设计初稿，不是完整项目交付周期。
- 300 人天 / 约 15 万元是基于历史 133 个已完成需求、约 75% 覆盖率、单项目净省 3 人天及 500 元 / 人天的年化保守测算，未扣除建设、维护与运行费用。
- 原方案维护成本存在口径冲突，因此没有使用年化维护值及投入倍数。
- 7 条产品线为团队支撑范围，不代表 7 条线均已完成规模化上线；分类名称以实际台账为准。
- 26–49 元来自原方案长会话样本价格折算，非单需求账单或当前实时报价。
- 未来连接产品知识库、研发代码与测试的能力已明确标为规划。
