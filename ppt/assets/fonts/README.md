# 内置演讲字体

本项目以 CSS 名称 `UED Sans` 统一调用 Noto Sans SC 可变字体，包含中文、拉丁字母和数字，支持 100–900 字重。浏览器从本目录直接加载 WOFF2，离线可用，不依赖系统安装字体。

- 官方来源：[Google Fonts / Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)
- 原始文件：`NotoSansSC[wght].ttf`
- 原始下载地址：https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf
- 本地文件：`NotoSansSC-variable.woff2`（使用 fontTools 转为 WOFF2，保留完整字形及可变字重，不做字符子集裁剪）
- 许可：[SIL Open Font License 1.1](OFL.txt)

各操作系统的文字抗锯齿仍可能略有差异，但字形、字重与排版所用字体保持统一。
