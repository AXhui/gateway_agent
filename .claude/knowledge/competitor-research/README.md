# 竞品调研框架

> 当产品给 PRD 时，用这个框架系统性地调研海外竞品，把结论沉淀到本目录。
> 本文件是「方法」，各次调研结论另存独立文件。

---

## 一、调研触发与目标

触发：PRD 涉及某个产品形态/技术路线/场景时。
目标：回答三问——
1. 这条赛道上，海外玩家已经做到什么程度（参数、形态、定价、场景）？
2. 我们的方案是「补位」还是「重新发明轮子」？
3. 有没有可直接对标/借鉴的成熟形态与参数基线？

## 三、对标维度（每份调研报告统一用）

1. **产品形态**：硬件形态 / 供电 / 安装方式 / 尺寸
2. **关键参数**：量程 / 精度 / 分辨率 / 响应时间 / 电池寿命 / 通信距离 / IP 防护等级
3. **连接与协议**：LoRaWAN / NB-IoT / LTE-M / 蜂窝 / Wi-Fi / BACnet / Modbus / MQTT
4. **软件与云**：云平台 / 私有化 / API / OTA / 告警 / 可视化
5. **合规认证**：FCC / CE / ISED / PTCRB / 其他
6. **定价与商业模式**：硬件价 / 订阅 / 授权 / 最低起订
7. **差异化**：我们的方案相对竞品的真实差异点或成本/体验优势

---

## 四、调研方法

1. 官网产品页 + 数据手册（datasheet）——参数基线最权威。
2. 竞品横向对比（同类产品摆一起比参数）。
3. 行业评测 / 集成商白皮书 / 论坛（Reddit r/LoRaWAN、r/IoT 等）——真实口碑与坑。
4. 定价公开页 / 分销商（Digi-Key、Mouser、Alibaba）——成本锚点。
