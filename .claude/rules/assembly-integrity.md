# 装配完整性自检 · Assembly Integrity

> **适用范围**：A4 渲染（一切把 `tokens.css` / `library/*.css` / `registry-*.js` 内联进单文件 demo 的场景）与 A5 校验（R1 前置动作）。
> **性质**：硬性约束。装配产出的 demo 必须「字节完整」，内联块首尾截断**零报错零警告**，只能靠本自检拦截。

## 1. 失败家族：内联块首字节截断

把 CSS/JS 源文件内联进 demo 时，若丢失块的**开头若干字节**，会产生「整体静默失效」：

| 案例 | 丢失内容 | 后果 |
|---|---|---|
| REQ-011 | `<style>` 开标签 | 整块 CSS 变纯文本，页面裸奔 |
| REQ-013 | `tokens.css` 首行注释开头 `/* ====…` | 残留 `*/` 把 `:root{…}` 粘成非法限定规则，解析器丢弃整块 → **全部 CSS 变量失效**：`var()` 塌陷为初始值（gap:normal、padding:0），无约束 `<svg>` 按 300×300 渲染 |

同族特征：**控制台无任何报错**、页面「半可用」，视觉表现为间距塌陷/图标巨大/布局挤压，极易漏检。

## 2. 自检动作（A4 装配后必做，二选一，推荐双跑）

1. **令牌活性断言**（浏览器或 Playwright 执行）：

   ```js
   const v = getComputedStyle(document.documentElement).getPropertyValue('--spacing-24');
   if (!v.trim()) throw new Error('装配截断：:root 令牌块未生效');
   ```

   同时抽查一个非零间距元素的 computed `gap` / `padding` 不为初始值。

2. **首尾字节 diff**：对每个内联块，与源文件比对开头 64 字节与结尾 64 字节（`head -c 64` / `tail -c 64`）。首部注释、开标签、`@charset`、`(function(){` 等开头标记缺失即截断。
