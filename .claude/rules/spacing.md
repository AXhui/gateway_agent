# 内容区间距与尺寸红线 · Content Spacing & Sizing Red-lines

> **适用范围**：demo 页面**内容区**的一切装配产物——A4 渲染稿、`M_*` 模块 / `T_*` 模板编排层、L3 业务组件 `render` 骨架内部的内容排版。
> **性质**：硬性约束（违反即打回）。所有数值一一对应 `tokens.css` 既有 `--spacing-*` 令牌；红线之外的裸间距、裸字号、越界图标尺寸即违规。
> **与既有文档的关系**：`encapsulation.md` §3 管「值必须来自令牌」，本文件管「令牌取值的下限与阶梯」；`page-assembly.md` 管「页面怎么拼 L3」，本文件管「拼完之后内容区的呼吸感」。L2 组件**内部**固有间距（如 Button 内 icon 与文字）以该组件 SKILL.md 契约为准，本文件不重定义、不覆盖。

## 1. 间距红线（最小值）

间距只能取令牌阶梯 `--spacing-*`（4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64），下表是各关系的**下限**：

| 关系 | 最小值 | 令牌 | 红线说明 |
|---|---|---|---|
| 按钮与按钮（同一操作区） | **12px** | `--spacing-m` | 主/次操作并排 gap 不得低于 12px，禁止贴边相邻 |
| 按钮与相邻交互控件（输入框/下拉） | **12px** | `--spacing-m` | 操作行内按钮与控件之间 |
| 卡片与卡片（同级栅格 gap） | **16px** | `--spacing-l` | 用 `mod-*` 布局类表达，禁止 0 / 4 / 8px |
| 模块与模块（区块纵向分节） | **24px** | `--spacing-2xl` | 区块间视觉必须可分辨 |
| 图标与文本（同排内联） | **4px** | `--spacing-xs` | 按钮内遵循 Button 契约（xs/sm 4px、lg 6px） |
| 标题与正文内容 | **12px** | `--spacing-m` | 标题下沿到第一行内容 |
| 标题与辅助说明 | **4px** | `--spacing-xs` | 副说明紧随主标题 |
| 表单项与表单项 | **16px**（推荐 24px） | `--spacing-l` / `--spacing-2xl` | 垂直表单行距 |
| 筛选/工具栏控件之间 | **8px**（推荐 12px） | `--spacing-s` / `--spacing-m` | 输入框、下拉、日期等横向排列 |
| 列表行与列表行 | **8px**（标准 12px） | `--spacing-s` / `--spacing-m` | 仅纯展示的紧凑列表允许 8px |
| 标签组内 tag 与 tag | **8px** | `--spacing-s` | — |

**通用下限**：任意两个元素可见间距不得为 0（视觉一体的复合体除外：图标+文字、输入框+前后缀、按钮组内的分段按钮）。**按钮类可交互元素之间一律 ≥ 12px**，无例外。

## 2. 容器内边距红线

| 容器 | 最小内边距 | 令牌 |
|---|---|---|
| 页面内容区（左右） | 24px | `--spacing-2xl` |
| 页面内容区（顶部，无页头时） | 24px | `--spacing-2xl` |
| 卡片（Card）内边距 | 16px（推荐 20 / 24px） | `--spacing-l` 起 |
| 弹窗 body | 16px | `--spacing-l` |
| 页头与内容区之间 | 16px | `--spacing-l` |
| 工具栏/筛选区与表格之间 | 12px | `--spacing-m` |

卡片上下内边距**对称**，最后一行内容不得贴底。

## 3. 图标尺寸与引用红线

- **尺寸区间硬限：16px ≤ size ≤ 44px**。正文/控件内图标 < 16px、任何图标 > 44px → 打回。
- **合法阶梯**：16 / 20 / 24 / 32 / 44。出现 17 / 18 / 22 等非阶梯值 → 打回。
- **例外**：徽标角标等装饰性微标允许 12px，但不得承载独立交互语义。
- **可点击图标热区 ≥ 24×24px**：视觉 16px 的图标必须以 padding 撑到 24px 热区（无障碍硬要求）。
- **引用铁律**：图标一律经 `S_Icon`（`MS_ICONS` / Lucide 集）表达。页面层 / L3 出现手写 `<svg>`、外链图标图片、emoji 充当图标 → 一票否决（与 R2 溯源同判）。
- **同组同尺寸**：同一按钮组 / 操作列 / 状态列内图标必须同尺寸。
- 图标颜色只允许 `--color-icon-*` 系列令牌。

## 4. 标题引用红线（层级与引用关系）

- **标题一律经 `S_Typography` 的 `level` 阶梯表达**，页面层 / L3 不得自写 `h1-h5` 标签 + 裸字号拼标题。
- **层级严格递进，禁止跳级**（H1 → H3 直接相邻即违规）；同级标题全页同 level。
- **场景绑定（写死映射）**：

| 场景 | 级别 | 规格 |
|---|---|---|
| 站点级大标题（一页至多一个） | H1 | 30px / 600 |
| 页面主标题 | H2 | 24px / 600 |
| 卡片标题 | H4 | 16px / 500 |
| 区块 / 分组标题 | H5 | 14px / 500 |
| 正文 | — | 14px / 400 |
| 辅助说明 | — | 12–14px + `--color-text-secondary` |

- **字号合法集合**：30 / 24 / 20 / 16 / 14 / 12（Typography 阶梯 + 12px 辅助文字）。集合外字号即违规（`--font-mono` 代码场景除外）。
- **数值展示家族**（Statistic / 指标卡 / 协议卡数值，仅限数字+单位）：28 / 24 / 20 / 18 / 16。18px 只允许数值展示，不得用于普通文案；13px 全场景禁用（改 12 或 14）。
- 标题颜色只允许 `--color-text-primary`；语义色标题只允许对应语义 token（如错误标题用 `--color-error-normal`）。

## 5. 校验挂钩

| 规则 | 拦截的违规 | 对应条款 |
|---|---|---|
| R1 令牌合规（扩展） | 裸间距 / 裸字号 / 图标尺寸越界或脱离阶梯 | §1 §3 §4 |
| R2 组件溯源 | 手写 `<svg>` 图标、裸标题标签 + 内联字号 | §3 §4 引用铁律 |

R1 校验范围从「查色值」扩展为「查色值 + 间距/字号/图标尺寸是否落在本文件映射表」（见 `knowledge/K_validation.md`）。

## 6. 边界

- L2 组件内部固有间距（Button 高度档位、Input 内边距、Modal 结构间距）以各自 SKILL.md 契约为唯一真源，本文件不重定义、不覆盖。
- 页面级纯结构（栅格 gap、区块间距）允许由 `mod-*` 结构类承载 §1 / §2 的值。
- Figma 侧（A7 / A8）对照本表同值执行；demo 与设计稿共用一套红线。

## 7. 与运行时层的同步状态

**权威方向**：本文件是唯一权威；运行时层（`assets/js/registry-business.js`、`library/base.css`、`library/business.css`）保留源头原值不动，已知偏差**在 A4 内联生成 demo 时就地修正**（机械替换），不回写 assets 源头。

### 存量偏差清单（两边同维护：改任一侧必须同步本表）

| 偏差 | 位置 | 红线值 | demo 内联时动作 |
|---|---|---|---|
| `ico(*, 14)` ×41 | `registry-business.js` | 图标 ≥16（阶梯 16 起） | 批量替换为 `ico(*, 16)` |
| 按钮组 `ms-space--8` ×11 | `registry-business.js`（工具栏/批量操作/卡片底操作） | 按钮间 ≥12 | 替换为 `ms-space--12`（标签组等非交互场景保留 `--8`） |
| `.ms-stat-title` 13px | `library/base.css` | 字号 12 或 14，13 全场景禁用 | 内联 CSS 改 12px |
| `.bc-eg71-protocol-card` 竖向 padding 12px | `library/business.css` | 卡片内边距 ≥16 | 内联 CSS 改 16px |

### 同步约定

1. A4 渲染器内联 runtime 后按本清单逐项修正，修正只落在 demo 文件，**不改动 assets 源头**。
2. 未来统一升级 runtime 源头时，逐项对齐本文件后从清单删除对应行，并同步删除三个 runtime 文件头部注释中的偏差标记。
3. 新增业务组件 / 新增 CSS 落库前先过本红线，**不得新增偏差清单条目**。
